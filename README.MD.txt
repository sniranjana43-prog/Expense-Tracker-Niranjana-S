## How to Run

You can run the project directly in your browser — no installation, build tools, or external dependencies are required.

### Option 1: Open Directly

1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application will open in your default browser.

> Note: Most features work directly from `index.html`. For the best experience, especially when working with browser APIs or local files, using a local server is recommended.

### Option 2: Run with a Local Server

#### Using Python

If Python is installed on your system, open a terminal inside the project folder and run:

```bash
python -m http.server 8000
```

Then open:

**http://localhost:8000**

#### Using Node.js

If Node.js is installed, run:

```bash
npx serve .
```

The terminal will display a local URL such as:

```text
http://localhost:3000
```

Open that URL in your browser.

### Stop the Server

To stop the local server, press:

```text
Ctrl + C
```

### Requirements

* A modern web browser such as Chrome, Firefox, Edge, or Brave
* Python 3 or Node.js (only if using a local server)
* No database or additional dependencies required

That's it! 🚀
